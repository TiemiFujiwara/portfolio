# Tiemi Fujiwara - Portfolio Web 2026

> "Work in Progress".

This is a One-Page Personal Portfolio built with HTML5, CSS3, JavaScript and Bootstrap 5. The content is mainly focused in **Digital Design** and **Illustrations**.

**Live Preview:** [tiemi-fujiwara-462cd.web.app](https://tiemi-fujiwara-462cd.web.app/)

---

### ✿ Features

- **Responsive Design:** The website is designed to be responsive and work on all devices, some will not have features that other does.
- **Parallax Hero Section(For Desktop only):** Multi-layer illustration, made by the author, reactive to mouse movement.
- **Gallery & Modals(All devices):** Grid layout with preview of the works. And modals with full art, title and description.
- **Scroll Reveal(All devices):** Smooth revealing animation for sections, made with JS.
- **Performance:** All assets optimized with WebP format for faster load times.
- **Contact form(Unfinished):** A working forms that sends your message to the author's email.

---

### ✿ Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
